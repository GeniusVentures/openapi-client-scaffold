## Overview

Ship the Core UI Foundation — 28 generic widget atoms + the ScaffoldMotion
utility consumed by every Genius Network app, plus 3 Jinja2-template-generated
composites (ScaffoldCard, ScaffoldStateView, ScaffoldSearchBar) — then the
media and integration widgets (MediaCard, MediaControls, WalletConnectSheet)
that compose those atoms. All widgets are generic, M3-themed, and carry zero
app-specific business logic; they consume only `Theme.of(context)` and
previously-shipped scaffold atoms.

## Milestone Summary

**Key Decisions:**

- **Atoms are the primitives, composites are the recipes** — ScaffoldCard, ScaffoldStateView, ScaffoldSearchBar are Jinja2-template-generated compositions of atoms; the atoms are the ingredients.
- **Template boundary: composition-by-intent vs configuration-by-state** — a template exists when the composition of atoms varies by intent (card variants), not by runtime state. Atoms like ScaffoldBadge are plain parameterized widgets.
- **Dependency layering determines wave ordering** — Wave 0 zero-dep foundations, Wave 1 single-dep atoms, Wave 2 multi-dep, Wave 3 composites; strictly sequential.
- **Composable `ScaffoldSlider` base widget** (extracted during Phase 7 UAT) — buffered span painted in-track via a custom SliderTrackShape sharing one coordinate space; MediaControls composes it rather than embedding slider logic.
- **All v1.1 widgets consume only `Theme.of(context)`** — no Riverpod, no GeniusTheme, no app-specific logic; exported via the `frontend_scaffold` barrel.

**Issues Resolved:**

- MediaControls seekbar drag-stall (mid-gesture subtree teardown) — fixed via unconditional track-shape install.
- MediaControls label jitter/overflow — measured labels via TextPainter (tabular figures + ambient textScaler, hour-magnitude seed).
- WalletConnectSheet address truncation — middle-truncate keeps `0x…` prefix + checksum tail.
- macOS window floor 420×480 — guarantees usable seekbar track.

**Issues Deferred:**

- Golden-test infrastructure for ScaffoldSlider buffered-paint rendering assertion (IN-06, code review) — deferred; no golden infra in repo.
- Light default palette to complement dark-seeded ScaffoldPalette defaults — carried from v1.0.

**Technical Debt Incurred:**

- None significant. Template/codegen drift on media_card caught and fixed (WR-03); CI regenerate-and-diff remains the guard.
