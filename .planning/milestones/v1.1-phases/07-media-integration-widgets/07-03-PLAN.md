<objective>
Ship WalletConnectSheet (WIDG-31) — a bottom-sheet presentation wrapper over `ResponsiveDrawer.show` that displays Reown WalletConnect session state. Disconnected state shows a QR-connect surface driven by a consumer-supplied `qrBuilder: Widget Function(BuildContext, String uri)` (D-05 — scaffold gains NO QR dependency). Connected state shows the truncated wallet address, a network chip (ScaffoldBadge), and a Disconnect action. Session state is passed in externally; the sheet owns no Reown session.

Purpose: Shared Reown session UI per genius-tube ADR-002, consumed by genius-tube Phase 4 and GeniusWallet. D-05 keeps the QR rendering choice with the consumer (qr_flutter, custom painter, etc.).
Output: 1 widget, 1 test file, 1 demo.
</objective>
