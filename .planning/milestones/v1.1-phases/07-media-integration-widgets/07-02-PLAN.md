<objective>
Ship MediaControls (WIDG-30) — a generic M3 overlay control bar with play/pause toggle, seekbar showing buffered amount, volume mute/unmute, fullscreen enter/exit. All callbacks optional and no-op when null. The widget renders from passed-in `isPlaying` / `position` / `duration` / `buffered`; a private StatefulWidget holds ONLY the transient seek-scrub during drag and emits `onSeek` on release (D-03). Time labels are shown by default and rendered with `ScaffoldFormattedValueDuration`, hideable via `showTimeLabels` (D-04).

Purpose: This is the second primary Phase 7 deliverable for genius-tube Phase 2. The D-03 pattern (no cubit, only transient scrub state) keeps playback truth in the consuming app's playback cubit.
Output: 1 widget, 1 test file, 1 demo.
</objective>
