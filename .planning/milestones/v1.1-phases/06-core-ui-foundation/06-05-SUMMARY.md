## Accomplishments

- `ScaffoldSelectableSurface` — composes `ScaffoldSurface` + `ScaffoldPressable`: unselected `deepBlueCardColor`; selected adds a 12%-opacity `lightGreenPrimary` overlay + 1px `lightGreenPrimary` border via `AnimatedContainer` (medium/standard); focus ring, press state layer, and disabled dim inherited from `ScaffoldPressable`; `Semantics(selected:)`.
- `ScaffoldDraggable` — wraps `LongPressDraggable` inside `ScaffoldPressable` (long-press handler left null so the gesture reaches the draggable); default feedback is the child at 1.05x on `dragFeedbackBackground` with a card shadow, original fades to 0.4 opacity; optional `dragHandle` prepends `ScaffoldDragHandle` or a custom widget; lifecycle callbacks (`onDragStarted`/`onDragEnd`/`onDraggableCanceled`) adapted from the richer `Draggable` signatures.
- `ScaffoldDropTarget` — a `DragTarget`-based state machine (idle/overAccepted/overRejected/dropped) composing `ScaffoldSurface` + `ScaffoldStatusIndicator`: idle = dashed `borderSubtle` border; over-accepted = `dropZoneHighlight` tint + `lightGreenPrimary` border + info indicator; over-rejected = `dropZoneRejected` tint + `statusError` border + error indicator; dropped holds the accepted tint for 500ms before resetting (mounted-guarded timer, T-06-09).
- `ScaffoldFileInputSurface` — composes `ScaffoldSurface` + `ScaffoldDropTarget` + `ScaffoldStatusIndicator` + `ScaffoldDisabledOverlay`: idle dashed border + upload icon + label; valid `statusSuccess` 2px border + check circle + filename; invalid `statusError` 2px border + error icon + message; tap-to-pick calls `pickFile` (or `FilePicker.platform.pickFiles`) then `onFileSelected` + `validate`; `maxSize` guards oversized files (T-06-10).
- `ScaffoldDashedBorder` — a `CustomPaint` dashed rounded-rect border primitive (Flutter has no native dashed border), reused by both drop zones.
- Full gate green: `dart analyze --fatal-infos lib/ test/` clean; `flutter test` 143/143 passing (19 new tests); no hardcoded hex values.

## Decisions Made

- `ScaffoldDraggable` is non-generic (`dynamic data`) per the plan's contract; `LongPressDraggable<Object>` is used internally.
- `ScaffoldDropTarget.onAccept` is `ValueChanged<dynamic>?` (receives the dropped data) instead of the plan's `VoidCallback?`, because `ScaffoldFileInputSurface` needs the dropped `File` to route to `onFileSelected`. This is the only API deviation; plain drop-zone consumers can ignore the argument.
- `ScaffoldDropTarget.showIdleBorder` (default `true`) lets `ScaffoldFileInputSurface` own its idle/valid/invalid border without double-drawing the dashed border; the DropTarget still renders its over/dropped highlight.
- `file_picker` 6.2.1 added as a real dependency (present in the pub cache with all transitive deps; `flutter pub get` resolves offline; `flutter test` unaffected). The injectable `pickFile` callback remains the primary/test path, with `FilePicker.platform.pickFiles` as the runtime fallback.

**2. [Rule 1 - Bug] `PathMetric` not in scope**
- **Found during:** Task 2 (`dart analyze`)

- **Files modified:** `scaffold_dashed_border.dart`

**3. [Rule 1 - Bug] Test used a non-existent generic type argument**

- **Issue:** `ScaffoldDraggable<int>(...)` failed because the atom is non-generic (`dynamic data` per the plan).

- **Files modified:** `test/components/scaffold_draggable_test.dart`

**4. [Rule 2 - Missing critical functionality] Added `ScaffoldDashedBorder` primitive**

## Threat Model

- **T-06-09 (DoS, DropTarget rapid state transitions) — mitigated:** the 500ms `dropped → idle` `Timer` is canceled on re-entry and re-disposal; the callback is `mounted`-guarded and the timer is canceled in `dispose()`.
- **T-06-10 (DoS, FileInputSurface large file) — mitigated:** `maxSize` bounds checked before `validate` runs; `File.lengthSync()` is wrapped in a try/catch so an injected/nonexistent file defers to the consumer `validate` instead of throwing.
