  <action>
1. CONTRIBUTING.md, `### Theme tokens`. Keep the existing bullets and extend them. Plain words, no emojis.
   - Source: every REGIONS row as token path to Dart target:
     - `scaffold.shadows.dark` feeds the ScaffoldShadows constructor defaults (`defaultShadows`), and `.light` feeds `lightShadows`.
     - `scaffold.motion.durations` and `.curves` feed ScaffoldMotionTheme.
     - `scaffold.typography.textStyles` and `.fontFamilies` feed ScaffoldTypography.
     - `scaffold.gradients` feeds ScaffoldGradients.
     - `scaffold.colorRoles.dark` feeds the ScaffoldColorRoles defaults, and `.light` feeds `lightColorRoles`.
   - Region styles: "args" regions are arguments of a const constructor call. "params" regions are constructor parameter defaults, so every parameter of the new extensions is optional and `const X()` is the default instance.
   - Formats:
     - shadows: a list of `{color, blurRadius, offset}`, with offset a two-number list.
     - durations: integer milliseconds.
     - curves: `Curves.<name>` or a four-number list for a Cubic.
     - text styles: an object with a subset of fontFamily, fontSize, fontWeight (100 to 900), letterSpacing.
     - font family names: letters, digits, space, underscore, hyphen.
     - gradients: null only; a non-null gradient needs an encoder first.
     Every string format is validated by full match, and anything else fails the generator.
   - Fallbacks:
     - Each extension has a `context.<name>` getter (shadows, motion, typography, gradients, colorRoles) that returns the registered extension or a default.
     - shadows and colorRoles use the light instance when ThemeData.brightness is light.
     - With no ScaffoldColorRoles registered, accent and accentOnSurface come from the resolved palette's lightGreenPrimary and borderControl from its borderGrey.
     - `scaffoldThemeExtensions` deliberately still lists only the palette and dimens.
   - Compatibility: `ScaffoldElevation.card` and the static motion duration and curve classes stay as public constants. Tests pin them equal to the generated defaults. Widgets read the theme instead.
2. README.md: add scaffold_shadows, scaffold_motion_theme, scaffold_typography, scaffold_gradients and scaffold_color_roles to the `lib/theme/` row. Change the `generators.theme_defaults` family row so its first two cells say it covers the defaults of ScaffoldPalette, ScaffoldDimens and the five theme extensions.
