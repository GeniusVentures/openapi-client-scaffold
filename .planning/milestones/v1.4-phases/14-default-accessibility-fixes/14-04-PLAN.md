<objective>
Move every accent foreground call site onto color roles, without changing a pixel. This is the
structural half of the light-mode accent fix (UD-08, UD-09). Plan 14-05 then changes the light role
values, and re-baselines the captures in a separate commit.

Purpose: CLAUDE.md requires a behavior-preserving refactor before a behavior change, in separate
diffs. Today about twenty sites read the bright accent fill (palette.lightGreenPrimary #00EAAE,
lightGreenSecondary #01CC95) as a foreground on light surfaces, at 1.33 to 2.08:1. After this plan
they read roles whose values still equal the fill in both themes. 14-05 can then fix light mode by
changing token values only.

Design:
- `accentOnSurface` (exists since 13-02) is used for icons, borders, lines, dots and state graphics.
- New `accentSecondaryOnSurface` is used for the one site that draws lightGreenSecondary, the ActionButton icon. Mapping it to accentOnSurface would change its dark color, and dark must stay unchanged.
- New `accentTextOnSurface` is used for accent drawn as text, which needs 4.5:1 rather than 3:1 (UD-09).
- In this plan every role, in both themes and in fallbackFor, resolves to the same color the site drew before. Nothing renders differently.
