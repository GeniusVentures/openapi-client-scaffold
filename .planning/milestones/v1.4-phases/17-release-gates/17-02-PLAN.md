Planner decisions for this plan:
- PD-09 Harness port. Bash, kept as close to the session harness as possible so its proven output
  carries over; the port only removes machine knowledge and adds fail-early guards:
  - Usage: `gcs_check.sh <gcs-app-dir> <scaffold-ref>`; both required; usage message and exit 2
    when missing.
  - Scaffold repo: `git -C "$(dirname "$0")" rev-parse --show-toplevel`.
  - flutter: required on PATH (`command -v flutter`); the script does not edit PATH.
    Python: `${PYTHON:-python}`, checked with `command -v`.
  - Restore target: the submodule's own HEAD, read before the checkout; the trap restores to it.
  - Guards before any change: `<app>/scaffold` is a git work tree, `<app>/templates/components`
    exists, and `git -C <app>/scaffold status --porcelain` is empty; each failure exits 2 with a
    message.
  - Unchanged: the fetch refspecs, the detached checkout, deleting and re-rendering the gitignored
    `lib/generated/chat` (GCS `src/app/.gitignore` line 51), the 4 components x 3 kinds codegen loop
    with both `--template-dir` values, pub get, analyze, test, and every summary line's wording, so
    two runs compare line for line. The component list stays explicit (it is GCS's template set,
    checked: 4 components, 12 templates, 4 vars files).
  - Stays in tools/, outside the brand scan's roots (lib/, example/, tokens/); naming the consumer in
    dev tooling is expected.
- PD-10 Notice snippet check: the "keep the old look" code goes into a scratch Dart test under
  test/theme/, which asserts the snippet's palette and roles equal the old values; run it with
  `flutter test` and `dart analyze --fatal-infos`, then delete it. `git status --porcelain -- test`
  must be empty afterwards.

Facts for the notice (checked during planning; re-check while writing):
- GCS `src/app/lib/theme/gcs_theme.dart` registers `ScaffoldPalette.lightPalette` (light) and
  `ScaffoldPalette.defaultPalette` (dark) and no `ScaffoldColorRoles`, so GCS gets the role fallback
  (`fallbackForPalette`) and every light and dark palette change in 14-COLOR-CHANGES.md.
- `ScaffoldPalette.copyWith` exists (lib/theme/scaffold_palette.dart ~163);
  `ScaffoldColorRoles.lightColorRoles` is a static const (lib/theme/scaffold_color_roles.dart ~98)
  and `ScaffoldColorRoles.copyWith` exists (~159).
- Midnight opt-in API: README "Midnight preset (opt-in)": deep import
  `package:frontend_scaffold/theme/presets/midnight_theme.dart`, `midnightTheme(brightness)`,
  `midnightExtensions(brightness)`, fonts not bundled.
- GCS reads the M3 keys of design_tokens.json under StrictUndefined; those keys and the CSS snapshot
  are unchanged in v1.4.
