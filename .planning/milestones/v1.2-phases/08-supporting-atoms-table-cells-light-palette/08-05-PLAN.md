| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-05-01 | Tampering | User-typed text | accept | The composer clears the controller after `onSubmit` — the string crosses to the consumer once via the callback; no internal state to tamper with |
| T-08-05-02 | Information Disclosure | Text controller content | accept | Transient in-process state — no persistence, no logging in the atom |
| T-08-05-03 | Denial of Service | Huge badgeRow/actionRow lists | accept | Consumer responsibility — Wrap and Row lay out unbounded children; no virtualization in atom |
| T-08-05-04 | Elevation of Privilege | None — atom holds no secrets | accept | TextEditingController + FocusNode are the only state — disposed in `dispose()` |
</threat_model>
