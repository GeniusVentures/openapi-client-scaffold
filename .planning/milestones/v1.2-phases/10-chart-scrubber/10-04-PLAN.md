Ship `ScaffoldChartScrubber<T>` — the point-selection atom that composes with `ScaffoldChart<T>` to close WIDG-36. The scrubber owns keyboard navigation, focus outline, touch-target expansion, PointerExit clearing, and the scrub-area Semantics label. It does NOT render a tooltip or readout — the consumer composes the readout externally using their own `selectedPoint` state (D-05).

Purpose: This is the a11y + interaction layer around the chart. fl_chart's LineTouchData handles tap/drag inside the chart widget itself; the scrubber adds the keyboard + focus + hover-exit + 48x48 hit-area affordances that turn "a chart you can tap" into "a chart you can scrub accessibly."

Keyboard navigation rules:
- ArrowRight: if selectedPoint == null → select series.first; else find index of selectedPoint in series (by identity OR by accessor-equality — use accessor-equality: `series.indexWhere((item) => xAccessor(item) == xAccessor(selectedPoint!) && yAccessor(item) == yAccessor(selectedPoint!))`); select series[(idx + 1).clamp(0, series.length - 1)].
- ArrowLeft: same, but select series[(idx - 1).clamp(0, series.length - 1)]; if selectedPoint == null → series.last.
- Enter: no-op if selectedPoint == null; else fire onPointSelected(selectedPoint!) again (confirmation — consumer may use it to lock a value or open details). Note: this fires the callback with the SAME value; consumers distinguish by tracking state externally.
- Escape: fire onPointSelected(null) unconditionally.
- Empty series: all four actions are no-ops.

Intent classes: define private `class _PrevIntent extends Intent { const _PrevIntent(); }` etc. at the bottom of the file.
