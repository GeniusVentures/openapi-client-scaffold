```text
class ScaffoldChart<T> extends StatelessWidget {
  const ScaffoldChart({
    super.key,
    required this.series,
    required this.xAccessor,
    required this.yAccessor,
    this.selectedPoint,
    this.onPointSelected,
    this.plotHeight,           // double? — if null, uses LayoutBuilder maxHeight
    this.lineColor,            // Color? — defaults to palette.lightGreenPrimary
    this.semanticsLabel,       // String? — defaults to 'Chart'
    this.xLabelFormatter,      // String Function(double x)? — defaults to x.toStringAsFixed(0)
    this.yLabelFormatter,      // String Function(double value, double step)? — defaults to chartAxisLabel
    this.viewMinX,             // double? — visible window override
    this.viewMaxX,             // double? — visible window override
  });

  final List<T> series;
  final double Function(T) xAccessor;
  final double Function(T) yAccessor;
  final T? selectedPoint;
  final ValueChanged<T>? onPointSelected;
  final double? plotHeight;
  final Color? lineColor;
  final String? semanticsLabel;
  final String Function(double)? xLabelFormatter;
  final String Function(double, double)? yLabelFormatter;
  final double? viewMinX;
  final double? viewMaxX;
}
```

Note on selectedPoint: the atom does NOT visually render selectedPoint itself (no tooltip, no readout — D-05). It forwards selectedPoint only to highlight logic internal to the touch indicator (handled by fl_chart's LineTouchData when the user is actively touching). If selectedPoint is provided externally WITHOUT touch interaction, the atom does NOT paint a persistent dot — visual selection state is the consumer's job (via composition with ScaffoldChartScrubber in Plan 04 which adds keyboard selection rendering).

Mapping rules (atom responsibilities):
1. If series.isEmpty → return Semantics(label: semanticsLabel ?? 'Chart', child: SizedBox.shrink()).
2. Map series to spots: `spots = [for (final item in series) (x: xAccessor(item), y: yAccessor(item))]`.
3. Resolve visible window: `lo = viewMinX ?? spots.first.x; hi = viewMaxX ?? spots.last.x;`.
4. Compute `visibleSpots = spots.where((s) => s.x >= lo && s.x <= hi).toList()`; if empty, fall back to whole series.
5. Compute yBounds: find visible min/max y, apply 8% padding, flat-series fallback to ±1% of value. Implement this inline (or add a chartYBounds helper to chart_geometry if missing — if missing, extend chart_geometry with `(double, double) chartYBounds(List<ChartPoint> data, {double? viewMinX, double? viewMaxX})` returning 8%-padded visible Y range with flat-series fallback to ±1%).
6. Resolve plotHeight: use this.plotHeight if provided, else LayoutBuilder maxHeight; if unbounded, throw a clear assertion error.
7. useFrame = chartUsesFrame(plotHeight).
8. If !useFrame: yBounds = chartBandedBounds(yBounds, plotHeight).
9. Resolve colors: lineColor ?? palette.lightGreenPrimary; borderControl = palette.borderControl; borderSubtle = palette.borderSubtle; textSecondary = palette.textSecondary; axisLabelStyle = textTheme.labelSmall.copyWith(color: textSecondary, fontFeatures: [FontFeature.tabularFigures()]).
10. reducedMotion = ScaffoldMotion.of(context).reducedMotion.
11. Build the LineChart widget via buildScaffoldLineChart(spots: visibleSpots, plotHeight: plotHeight, plotWidth: constraints.maxWidth, lineColor: ..., borderControl: ..., borderSubtle: ..., textSecondary: ..., axisLabelStyle: ..., reducedMotion: ..., onSpotTouched: onPointSelected == null ? null : (int spotIndex) => onPointSelected!(visibleSpots[spotIndex] == selectedPoint ? null : series.firstWhere((item) => xAccessor(item) == visibleSpots[spotIndex].x && yAccessor(item) == visibleSpots[spotIndex].y)), viewMinX: lo, viewMaxX: hi, yBounds: yBounds, minX: lo, maxX: hi).

    Note on index mapping: fl_chart's touchCallback reports `spotIndex` — an index into `lineBarsData[0].spots`. Because the atom passes `visibleSpots` (NOT the full series), the index maps into `visibleSpots`. To recover T: maintain a parallel `visibleItems` list alongside `visibleSpots` so `visibleItems[spotIndex]` directly gives T. Build both lists in a single pass.
12. If useFrame: also build the X-axis label row per D-06 — LayoutBuilder over the row's width, chartXLabelCount(plotWidth: width, sampleCount: visibleSpots.length), then a Row with mainAxisAlignment.spaceBetween, Padding(EdgeInsets.only(right: kChartAxisGutter)), children = List.generate(count, (b) { ix = count > 1 ? ((b/(count-1)) * (visibleSpots.length-1)).round() : 0; return Text(xLabelFormatter?.call(visibleSpots[ix].x) ?? visibleSpots[ix].x.toStringAsFixed(0), style: axisLabelStyle); }).
13. Compose: ScaffoldSurface(fill: palette.surfaceElevated, border: none, borderRadius: dimens.radiusMd, padding: EdgeInsets.all(dimens.space8), child: Column(children: [Expanded(child: lineChart), if (useFrame) SizedBox(height: dimens.space4), if (useFrame) xLabelRow])).
14. Wrap the whole thing in Semantics(label: semanticsLabel ?? 'Chart').

Atom is a StatelessWidget. No state held. The touch-to-T mapping is recomputed per build — cheap, deterministic, no caching needed for v1.2.
