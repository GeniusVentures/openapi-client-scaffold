    1. Call `_pump` with a `SizedBox(width: 800, height: 600, child:

    5. `final ByteData? bytes = await image.toByteData(format: ui.ImageByteFormat.png);`
    6. `await File('../images/$filename.png').create(recursive: true).then((f) => f.writeAsBytes(bytes!.buffer.asUint8List()));`

       because `flutter test` runs from `example/`.
