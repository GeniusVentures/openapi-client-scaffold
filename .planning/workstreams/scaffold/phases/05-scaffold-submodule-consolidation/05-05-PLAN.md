<objective>
Port the GeniusWallet toast redesign (`redesign/toast-notification-260808`) into the
`frontend_scaffold` package so the scaffold — not any one app — owns the authoritative
toast UX going forward.

The redesign changes the toast's public API and UX contract:
- `title` becomes optional (`String?`); title-less toasts are `ToastDensity.compact`
  (2s receipt), titled toasts are `ToastDensity.card` (alert with dismiss affordance)
- Message-first call style: `show(context, message, {title, type})` — "one notification,
  one call, everywhere"
- Visual: status color on leading edge + icon only; title/message on neutral text ladder;
  safe-area aware (per sketch-079)

Purpose: Phase 6's Cubit templates will generate toast calls; they must generate against
the NEW API, or generated code is wrong the moment the redesign merges upstream.
Output: scaffold commits porting the redesign, preserving our CR-02..04 lifecycle fixes,
plus a real test suite.
</objective>
