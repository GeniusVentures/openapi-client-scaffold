Planner decisions (Claude's discretion, shared by every plan and the verifier):
- PD-01 Null means built-in. Every extension field this phase adds is nullable. Its default token is
  `null`, and a widget that reads null renders exactly today's widget tree. Midnight supplies the
  value. The theme generators accept `null` for every literal kind in a `params` region (today only
  gradients do), emitting `this.name,`. An `args` region still rejects null, so a default `light`
  region omits nullable keys and the light instance inherits null from the constructor.
- PD-02 Placement. Colors go on ScaffoldColorRoles as use-named roles. Shadows go on ScaffoldShadows,
  gradients on ScaffoldGradients. Radii and stroke widths go on a new ScaffoldShapes extension
  (plan 16-04), because THM-06 freezes the ScaffoldDimens constructor. ScaffoldShapes is exported
  from the barrel and has a `context.shapes` getter. `scaffoldThemeExtensions` keeps listing only the
  palette and dimens.
- PD-03 Midnight instances. New values go into the existing generated Midnight consts through
  `scaffold.*` in tokens/midnight.json. Two new generated consts: ScaffoldGradients as
  `Midnight.darkScaffoldGradients` / `lightScaffoldGradients` (the `darkGradients` name is taken by
  MidnightGradients) and ScaffoldShapes as `Midnight.shapes`. midnightExtensions registers both.
  Where a new value equals an existing preset token, test/theme/midnight_token_map_test.dart pins
  the equality so the two cannot drift.
- PD-04 Restyles capture. The existing captures do not show cards, hover, checkboxes or a focused
  field (they sit below the kitchen-sink fold or are unfocused). A harness-private `_RestylesCapture`
  rendered only by the midnight test writes images/midnight/restyles_{dark,light}.png. The default
  profile never renders it, so images/ keeps exactly its 52 files.
- PD-05 Source over FEATURES where they disagree, AA over fidelity (Phase 15 PD-03). Values are in
  the table below; each plan cites its rows.
- PD-06 Hover. A hovered ScaffoldPressable paints hoverFill and hoverEdge with an optional
  borderRadius. Pressed keeps today's 12% textPrimary layer (plan 16-03).
- PD-07 Commit order in each plan: refactor commits first, with both profiles byte-identical; then
  the feature commit, with the default profile byte-identical; then a chore commit with only
  images/midnight/. No attribution trailer and no mention of Claude in any message.
