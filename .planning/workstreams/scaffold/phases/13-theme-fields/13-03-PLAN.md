- Doc comments that name a static duration or curve as the source now name the ScaffoldMotionTheme field instead (for example `[ScaffoldMotionTheme.medium]`).
- Drop an import of scaffold_motion.dart only if the file no longer uses ScaffoldMotion; the analyzer flags unused imports. Add the scaffold_theme.dart import where it is missing.
