Public API surface to ship (function signatures only — no fenced code blocks):

- `const double kChartFrameMinHeight` = 220.0
- `const double kChartAxisGutter` = 62.0
- `const double kChartTimeRowHeight` = 22.0
- `const double kChartLabelBand` = 17.0
- `const double kChartFillFadeStop` = 0.62

- `typedef ChartPoint = ({double x, double y});` — scaffold-neutral record replacing FlSpot at the geometry layer (D-02 isolation: the geometry file MUST NOT import fl_chart).

- `(List<double> values, double step) chartTickStep(double lo, double hi, int want)` — nice-number tick ladder with multipliers [1.0, 1.5, 2.0, 2.5, 3.0, 4.0, 5.0, 10.0]. Returns the candidate whose tick count is closest to `want`, among candidates with at least 2 values. `span <= 0` returns `([lo], 1.0)`.

- `String chartAxisLabel(double value, double step)` — precision derived from step: `decimals = step >= 1 ? 0 : min(8, (-log(step) / ln10).ceil() + 1)`. Returns `value.toStringAsFixed(decimals)` — NO currency symbol, NO NumberFormat/intl dependency (neutral scaffold, D-04).

- `int chartXLabelCount({required double plotWidth, required int sampleCount})` — `max(2, min(min(6, (plotWidth / 110).floor()), sampleCount))`.

- `int chartYTickCount(double plotHeight)` — `max(3, min(6, (plotHeight / 76).round()))`.

- `bool chartUsesFrame(double plotHeight)` — `plotHeight >= kChartFrameMinHeight`.

- `(double lo, double hi) chartBandedBounds((double lo, double hi) bounds, double plotHeight, {double band = kChartLabelBand})` — widens the window so original lo/hi land `band` px inside each edge. If `plotHeight - 2 * band <= 0` return the input bounds unchanged.

- `(ChartPoint high, ChartPoint low)? chartVisibleExtremes(List<ChartPoint> data, {double? viewMinX, double? viewMaxX})` — highest/lowest spot inside the window; falls back to whole series when the window selects nothing; returns null for empty list or flat series (high.y == low.y).
